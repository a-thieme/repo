# Plan: Consolidate Winner Determination in Shared Spec

## Goal
Remove duplicate winner determination sections from hydra-spec and auction-spec by moving the common algorithm to shared-spec.

## Changes

### 1. Add Winner Determination to shared-spec
Add new Section 8 "Winner Determination" with the standardized algorithm:

```
8. Winner Determination

When a node determines that a job is under-replicated, it MUST compute winners
as follows:

8.1 Filter

Exclude any node that:
	- Is already assigned the job
	- Has storage utilization exceeding STORAGE_THRESHOLD

8.2 Sort

Sort remaining candidates by:
	Primary:   Storage utilization percentage ascending
	Secondary: Capacity descending (larger capacity first)
	Tertiary:  Node name ascending (lexicographic)

8.3 Select

Select top N candidates where N = ReplicationFactor - CurrentReplicationCount
```

### 2. Update hydra-spec
- Remove Section 3 (Winner Determination)
- Add reference to shared-spec Section 8 where winner determination is needed:
  - Section 4 (Command Processing): "Compute winners per shared-spec Section 8"
  - Section 6 (Failure Recovery): "Compute winners per shared-spec Section 8"

### 3. Update auction-spec
- Remove Section 6 (Winner Determination)  
- Add reference to shared-spec Section 8 where winner determination is needed:
  - Section 7.1 (Auctioneer): "determine winners per shared-spec Section 8"
